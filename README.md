# 📚 SmartLearn LMS

A modern and responsive Learning Management System frontend built with React.

SmartLearn provides a clean learning experience where students can explore courses, view course details, track learning progress, and access a personalized dashboard.

## ✨ Features

- 🏠 Modern landing page
- 📚 Course catalog
- 🔎 Course search
- 🏷️ Category filtering
- 🎯 Level filtering
- 📖 Course details
- 📊 Student dashboard
- 📈 Learning progress tracking
- 🔐 Login interface
- 👁️ Password visibility toggle
- 🧭 React Router navigation
- 🔝 Automatic scroll-to-top navigation
- 📱 Responsive design
- 🎨 Clean and modern UI
